**Audit date:** 2026-11-19. All reruns used Python 3.12.5 and the versions in `results/run_manifest.json`. Original outputs in the working project were preserved; reruns were performed in an isolated copy and compared against saved artifacts/report values.

The original Singapore and San Juan figures were re-created with the committed runners, not edited by hand. The exact numeric matches confirm that the existing report's displayed result tables are consistent with code. Iquitos's detailed outputs were generated during the isolated rerun; only its cited summary values are retained in prose in the existing research notes.

The new level/change comparison and seasonal sensitivity tables are generated directly by `run_change_forecast.py`; its point-level predictions, summary values, DM results, and figures are all in `followup_experiments/results/` and `figures/`. The Singapore source overlap tables are generated by `singapore_analysis/check_overlap.py` from the frozen MOH source snapshots.

## Timing note

The code records median train and inference times. These are measurements of the local environment and are not expected to reproduce exactly. Consequently, timing columns and ratios derived from them are excluded from numeric equality checks. Forecast metrics and all generated non-timing figure content matched.
